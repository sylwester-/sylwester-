### Hi, I'm Sylwester

Software engineer by training, product leader by trade. I spend my days on cloud and AI platforms for the AEC industry, and my evenings building things end to end: hardware, firmware, backends, mobile apps and the agents that run on them.

**What I work on**

- **LLM systems that hold up in production.** Multi-model pipelines with deterministic checks, retries and fallbacks, structured outputs, and honest handling of refusals.
- **Evaluation before opinion.** Ground-truth benchmarks with held-out sets, model bake-offs on accuracy, latency and cost, and failure analysis that traces every miss to its cause.
- **Agents with guardrails.** Role-based agent setups where the cost of a wrong result decides what an agent may touch, with context and lessons that carry over from one session to the next.
- **Voice and accessibility.** Speech pipelines and assistive interfaces for people who cannot use a keyboard or their own voice.
- **Edge and infrastructure.** Custom ESP32 devices with signed over-the-air updates, and a self-run Kubernetes cluster and segmented network managed as code since 2022.
- **Regulated software.** Clinical-trials and healthcare platforms, where traceability and data protection are part of the design.

**Stack:** TypeScript, Python, Swift/SwiftUI, PHP, SQL, C++ (ESP32) on GCP, AWS, Kubernetes (k3s) and Firebase.

Most of my work lives in private repositories. I'm happy to walk through code and design decisions on request.
